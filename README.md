# Cosmic Explorer: Beyond Earth
Visit : teamxtream.ai.studio

An immersive, browser-based 3D educational space exploration game where students explore Earth, the Moon, and Mars with authentic planetary physics, verified NASA scientific discoveries, voice-guided educational narration, and interactive missions.

---

## 🚀 Key Features

### 1. Interactive 3D Universe
- Real-time Three.js simulation of the inner solar system containing the **Sun**, **Earth**, **the Moon**, and **Mars**.
- Dynamic orbital paths, axial rotation, and interactive raycasted planet selection.
- Deep space starfield with multi-spectral stellar coloration.

### 2. Authentic Planetary Physics
- Planet-specific gravitational acceleration:
  - **Earth**: 9.81 m/s²
  - **The Moon**: 1.62 m/s² (1/6th Earth gravity, enabling high floaty leaps)
  - **Mars**: 3.71 m/s² (38% Earth gravity)
- Camera-relative directional movement with inertia, deceleration, and continuous heightmap ground snapping.

### 3. Explorable Surface Worlds
- **The Moon (Mare Tranquillitatis)**:
  - Pitted regolith terrain and impact craters.
  - Apollo 11 Lunar Module Descent Stage exhibit.
  - Lunar Laser Ranging Retroreflector.
  - Permanently Shadowed Polar Crater Cold Traps with water ice reserves.
  - Apollo Passive Seismometer station.
  - Marius Hills volcanic lava tube skylight.
  - Apollo 17 orange pyroclastic volcanic glass.
- **Mars (Jezero Crater Paleolake)**:
  - Rolling iron-oxide sand dunes and dusty salmon-butterscotch sky.
  - NASA Perseverance Mars 2020 Rover with Mastcam-Z and MMRTG generator.
  - Jezero ancient river delta sediment fan.
  - Ripple-laminated mudstone and cross-bedded sandstone strata.
  - Titanium hermetic sample return depot tubes.
  - Atmospheric methane detection sensors.
  - Inverted riverbeds with smoothed conglomerate pebbles.
  - Dust devil vortex tracks and weather station.
  - Volcanic shergottite basalt rocks.

### 4. Verified Scientific Content Library
- 16 detailed, peer-reviewed educational records (8 Moon, 8 Mars).
- Dual reading levels: **Student Mode** (elementary/middle school) and **Planetary Scientist Mode** (high school/AP science).
- Every record links to official NASA, JPL, and LRO mission repositories.

### 5. Voice-Guided Narration Engine
- Free, browser-native Web Speech API narration in both **English** and **हिन्दी (Hindi)**.
- Integrated audio controls: Play, Pause, Resume, and Replay with live caption transcripts.

### 6. Virtual Explorer Backpack & Mission Progression
- Filterable and searchable specimen inventory with local persistence.
- Data-driven flight directives and mission checklists across Cadet, Specialist, and Commander tiers.
- Planetary Science Academy quiz system with constructive feedback and celebratory rewards.

### 7. Zero 404 / 100% Procedural Web Audio & Textures
- Procedural Web Audio API sound synthesizer for thrusters, footsteps, cushioned landings, interface pings, and collection fanfares.
- Canvas-generated dynamic textures for planetary globes and star particles.

## 🛠️ Controls

- **W, A, S, D / Arrow Keys**: Walk & navigate terrain
- **SPACEBAR**: Low-gravity leap
- **E**: Inspect nearby scientific beacon
- **Mouse Drag / Touch Swipe**: Orbit 3rd-person camera
- **B**: Open Explorer Backpack
- **M**: View Flight Mission Directives
- **Q**: Take Planetary Academy Quiz
- **H**: Return to Earth Mission Control HQ
- **S**: Audio & Display Settings
