# Asset & Scientific Verification Credits

## Scientific Sources & Repositories
- **NASA Space Science Data Coordinated Archive (NSSDCA)**: Apollo 11 Lunar Module and ALSEP Experiment specifications.
- **NASA Jet Propulsion Laboratory (JPL)**: Mars 2020 Perseverance Rover mission science data, instruments (PIXL, SHERLOC, RIMFAX, Mastcam-Z), and Jezero crater delta mapping.
- **Lunar Reconnaissance Orbiter Camera (LROC)**: Lunar South Pole permanent shadow regions and Marius Hills lava tube skylights.
- **NASA Astromaterials Research & Exploration Science (ARES)**: Apollo 17 pyroclastic orange glass and Martian shergottite meteorite analysis.

## Graphics & Audio Architecture
- **Textures**: 100% Procedurally generated HTML5 Canvas textures created at runtime (zero external HTTP image requests or CDN dependencies).
- **Audio**: 100% Procedurally synthesized sound effects and planetary ambience generated via the Web Audio API (zero audio file 404s).
- **Narration**: Browser-native Web Speech API (`window.speechSynthesis`) with dual-language support for English and Hindi.
